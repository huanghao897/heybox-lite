# Compose 迁移状态

当前分支：`feature/compose-migration`

## 已迁移

- Compose 应用壳、底部导航、页面路由和返回状态。
- 首页信息流、搜索、收藏/稍后看、我的、个人动态和阅读中心。
- 设置主页面及显示、数值、播放、缓存等子页面。
- 详情入口由 Compose 壳承接，但正文、评论、官方表情、多图、原图和互动暂时回落到原生详情宿主，沿用已经稳定的渲染与手势链路；Compose 详情组件保留在隔离边界内，待达到同等行为后再切换。
- 云端签到、签到日志、排行榜、登录表单和相关状态页面。
- 主要页面的控制器、异步缓存恢复、请求序列保护和资源释放。

## 保留的兼容层

- `ImageViewerActivity`：仍负责原生图片查看、缩放和手势退出。
- `VideoPlayerActivity`：仍负责播放器和手表媒体控制。
- 验证码/登录 WebView、崩溃恢复页、部分旧 ROM 兼容页。
- Java 网络、缓存、解析、加密和设备参数代码。

这些代码仍是未完成的迁移工作，不是全量迁移已经验收的证明。网络、解析、加密等 Java 非 UI 业务可以保留；正文、评论、图片、视频和恢复页的 UI 还需分别迁移并达到原版行为。验证码 WebView 仍是官方挑战页面的必要宿主，不将外部网页实现算作本应用 Compose UI。

## 回退与验证

- 原生 View 基线：`feature/ui-v2-native-view`。
- 当前分支不修改版本号，保持 `2.18 / 221`。
- 代码提交前必须通过 `:app:lintDebug`、`:app:testDebugUnitTest` 和签名 Release 构建。
- 圆屏、方屏、低内存设备、图片手势和播放器仍需要真机验证；构建通过不等于这些交互已经验收。

## 2026-10-03 交互回归修复

- 首页搜索框作为列表首项滚动，不再固定在页面顶部；加载和空列表也保留搜索入口。
- 首页、我的、搜索、阅读库和常规设置的滑动预览使用当前页面数据；目标页面按路由保持同一组合身份，交接时不重新创建目标页面。
- 手指位移只更新绘制层，不在每一帧重新组合帖子列表；取消与提交共用方向和位移规则。
- 原生详情入口不先把 Compose 路由切成详情，保留真实来源页面；清除旧原生页面，避免旧页面覆盖返回预览。
- 原生详情返回预览沿用同一页面渲染器和缓存状态，保留来源列表位置。预览不触发分页、表冠滚动和账号资料请求。
- 我的账号资料由独立控制器静默刷新，恢复头像、用户名、ID、关注、粉丝、获赞和签名；退出登录、切换账号及关闭页面宿主后拒绝过期回调。
- 设置开关使用 36x22 的紧凑轨道和等比例滑块，整行仍可点击，保留开关语义。
- 页面渲染分离到 `ComposeRouteScreen`，账号状态和请求分离到 `ComposeProfileState` / `ComposeProfileController`，转场几何分离到 `ComposeSwipePresentation`。

验证边界：纯逻辑和结构测试覆盖账号刷新、回调失效、拖动方向、全宽移动及路由交接；缺少已连接设备，尚未验收真实触摸事件、掉帧、图片加载观感和圆屏可点击范围。不得据此将全量迁移标记为完成。

## 阅读库回归修复与行为验证

- 阅读中心恢复可滚动页面，更新数据时保留已显示的缓存；继续阅读复用官方表情渲染，不再直接显示表情编码。
- 收藏夹恢复独立路由、文件夹名称和三级返回；返回已加载列表不清空列表、不重置标签。列表缓存按账号及收藏夹隔离，错误保留已有内容，并提供重试。缓存过期只在用户进入页面时刷新，不轮询。
- 云端历史恢复原有本地搜索与离线列表，返回预览复用相同关键词和滚动位置；不会因为每次重组而重新获取历史。
- 稍后看大小计算、磁盘读取和删除移出 UI 线程；后台失败保留原列表，销毁宿主后不再更新页面。
- 阅读统计恢复累计时长、总篇数、周均时长、真实星期和原版内容/社区比例条；计算提取为可测试状态映射。
- 阅读库拆为各自的页面和控制器，共享标题及搜索输入；不再把所有页面与磁盘请求混入 `ComposeFeedSaved` / `ComposeAppHost`。
- 圆屏标题与返回键移动到上方弦内；增加列表末尾可滚动距离，不压窄整个页面。
- JVM 控件测试覆盖圆屏末项滚动/点击、返回键圆形可达范围、紧凑开关的整行语义和历史搜索状态恢复。真实 View 渲染输出在 `app/build/outputs/ui-regression/reading-center-round.png`。
- Robolectric 与 Compose UI 测试仅加入测试/Debug 依赖，不进入 Release APK。项目内依赖下载设置连接与读取超时，避免无响应连接长期占用构建。

剩余验收：正文/评论的完整 Compose 替换、图片及播放器 UI、签到/排行与原设计的视觉比对、导航真实触摸测试、所有方屏/圆屏/低内存设备上的启动和帧率。当前工作不代表这些项目已经通过。

## 官方刷新动画与详情返回交接

- 从本地官方 APK 资源表核实 `header_refreshing`，复用与 Flutter `pull_refresh.lottie` 完全相同的动画。来源及 SHA-256 记录在 `third_party/official_pull_refresh/README.md`。
- 下拉由现有 Material 3 嵌套滚动处理；搜索框与卡片一起位移，不再使用独立 pointerInput 重复计算手势。刷新头沿用官方 70:50 比例、40% 开播点和 250 ms 收回；小屏按可用高度限制尺寸。
- 首次后台加载不冒充用户下拉刷新。非顶部滚动、反向收回、非活跃返回预览不会额外请求；动画关闭设置立即停止播放和收回动画。
- 详情退出不再创建第三份 Compose 返回页。`NativeDetailReturnHandoff` 接管手势中已经绘制的预览，保持组合、图片、滚动位置和宿主范围；实际目标页完成布局且完全显现后移除。
- 返回原路由时不重复准备/加载页面；渐进正文替换期间以完成手势的 pager 为准。取消或销毁后移除 Animator 回调，废弃的布局校正不再把返回帧拉回正文。
- `ByteString` 占位实现与 Lottie 的真实 Okio 冲突，已用正式依赖替代；保留原有类型签名和调用合同，没有改动官方接口、参数或认证协议。
- 真实控件测试验证拖动、单次刷新、原动画可解析、不同帧实际渲染、Compose 播放及离屏暂停；详情测试验证原组合不重建、图片层不脱窗、滚动保留、非全屏宿主、透明目标保护及销毁清理。JVM 图像输出位于 `app/build/outputs/ui-regression/official-refresh-frame.png`。

实机边界仍在：未连接手表，没有启动模拟器，不能仅凭 JVM 渲染和构建宣称所有 GPU 闪烁已经彻底消除。

## 刷新头滞留与分页卡顿修复

- 控件测试复现刷新同帧完成、回调拒绝请求及加载状态在拖动中改变时刷新头滞留。松手后保留一帧请求交接状态，让 Material 观察到完整刷新周期；不靠定时轮询、延迟重试或移除动画掩盖问题。
- 系统取消触摸会被 Compose 转换成已消费的抬起事件。只观察初始事件通道，不接管位移或消费手势；取消和非活跃页面不发起刷新，下一次正常下拉仍可使用。
- 分页响应解析、关键词过滤与去重合并交由单线程后台执行，主线程只发布列表与请求状态。保留原接口、游标、空结果保留旧列表及一次一个请求的行为；解析异常释放加载状态，宿主关闭后拒绝网络和后台旧结果。
- 卡片标题、摘要及内嵌游戏展示按内容缓存；列表设置稳定内容类型和页脚身份。点赞、关注及原 `FeedItem` 回调仍实时生效，不将可变业务对象伪标为不可变。
- 富文本按内容和样式变化绑定，不在无关重组时重新设文字、字体或表情；保留异步表情的 View tag 合同。字号或主题真正变化时更新渲染。
- 表冠事件使用独立动态 CompositionLocal，视觉主题保持稳定；真实控件测试验证连续 20 次表冠输入不重组独立主题控件，设置页仍逐次滚动且主题更新不重放旧滚动。

验证：`:app:testDebugUnitTest :app:lintDebug :app:assembleRelease` 成功，469 项测试无失败、错误或跳过。Lint 无错误，仍有 143 条既有警告和 21 条提示。尺寸限制、编码、重复类及 Release 签名校验通过；版本保持 `2.18 / 221`，固定证书保持不变，APK 内官方动画与来源哈希一致。

没有已连接设备，未启动模拟器；上述结果证明控件状态、后台任务边界和构建行为，不等于已经测得手表帧率，也不保证所有设备的 GPU 闪烁都已解决。本次不上传测试管理员、不部署服务器、不创建 Release。

## 签到页面、会员操作与信息流滑动

- 按六屏参考拆分签到概览、签到设置、会员服务、签到记录、记录详情和确认开通，保留当前黑灰配色和手机登录、配对、分享开关、撤销设备行为。
- 会员目录、兑换、购买记录接入独立 `CheckinMembershipApi`；订单与权益由服务器确认。默认视觉基准为 30 天 5 元、90 天 10 元，实际套餐、应付金额和币种不在客户端硬编码。非整额及非人民币只用于专门测试。
- 新增的三个网站接口沿用现有设备授权、账号隔离、限速及支付服务；相关源码与测试保留在本地 CheckinCenter 工作区，未整体提交或部署，未公开签到核心实现。
- 会员请求、扫码支付和签到记录由独立控制器负责，返回和应用后台时暂停支付查询；查询至少间隔 15 秒且同时最多一个。旧回调不能重新打开付款页或改变退出后的状态，同一套餐的待支付订单重入时复用，旧赞助模式更改金额后才重新建单。
- 签到记录沿用服务器实际执行结果与任务明细，不补造奖励或成功状态。小尺寸大字体下按钮和菜单可以换行，记录卡片调整内部排列，长详情内容留在独立面板内；支付二维码按圆形可视范围限制尺寸。
- 排行榜去掉赞助排行与其头像加载，保留连续签到榜、公开查看和已有返回逻辑。
- 信息流标题、摘要、内嵌游戏展示在后台预处理，与列表原子发布；分页保留旧项的展示缓存。富文本 View 在滚出和滚入时复用并清理旧表情标记，点赞和关注的可变状态单独发布，不因缓存而失效。

验证：Android 全量 629 项测试无失败、错误或跳过；网站会员、Lite API 和已有收费业务共 126 项测试通过。Lint 和固定签名 Release 构建通过，版本保持 `2.18 / 221`、包名和原有证书不变。控件测试覆盖 240x320 方屏、227x227 与 192x192 圆屏、160x240 窄屏以及大字浅色模式，逐字检查裁切和重叠、触摸验证按钮、解码实际绘制出的二维码像素；不依靠单个段落溢出标志判定布局。

验收边界：没有已连接设备，未启动模拟器；离线界面和支付夹具不代表真实签到、购买或到账。网站新接口尚未上线联调。正文、评论、图片、视频和恢复页面的兼容层仍需后续迁移，全量 Compose 目标没有标记完成。本批次不部署、不上传测试管理员、不创建 Release、不关机。
