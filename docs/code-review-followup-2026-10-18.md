## 状态与职责整理

- `ComposeDetailContext` 由当前详情路由派生，评论请求、缓存操作和诊断不再读取 Activity 中的 Compose 详情镜像；离开详情后不暴露旧帖子的写入上下文。父帖/个人页/子帖返回测试验证上下文随路由恢复。
